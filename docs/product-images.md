# Product imagery

The product cards use images supplied by the user and hosted on Cloudflare R2. The current variants are 100% cacao, 75% cacao with panela, and 75% cacao with stevia. Names, descriptions, images, and WhatsApp order messages remain editable in `src/content/landing-sections/products.md`.
